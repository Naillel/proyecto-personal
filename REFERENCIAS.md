## Comentarios sobre el proyecto
- El framework elegido es Vue 3 y se ha respetado durante todo el desarrollo.
- El proyecto es un juego educativo con pantalla de inicio, pantalla de juego y pantalla de resultado.
- Los datos se cargan dinámicamente desde un archivo JSON usando `fetch()`.
